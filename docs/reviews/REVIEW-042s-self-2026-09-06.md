## S3-3 — MEDIUM. The gate and the generators disagree about indentation, and the GATE is the wrong one.

`isRow()` matches `/^\s*\|/` — any indentation, tabs included. The generators
match `/^ {0,3}\|/`. **GFM allows at most three spaces; four makes an indented
code block, which is not a table row at all.**

So a four-space-indented row is **counted and cell-checked by the gate**, and
**silently skipped by both generators** — and it is not a table row in the first
place. ⚠ **This is the shape round one found as H2 and round two fixed only in
the generators.** No live instance.
