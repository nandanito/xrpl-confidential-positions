# Findings

## 1. HIGH — `finish()` wipes a copy of `sk_A`, but leaves the original scalar unwiped

**FILE:** [signer/src/keygen.rs:383–395]($REPO/signer/src/keygen.rs:383), supported by [signer/src/scalar.rs:132]($REPO/signer/src/scalar.rs:132)

`reduce_wide_total` returns this crate’s `scalar::Scalar`, a `Copy` wrapper around `[u8; 32]` with no `Drop`. `finish()`:

1. binds that secret as bare `sk`;
2. copies it into `sk_bytes`;
3. wraps and wipes only `sk_bytes`;
4. returns while the original `sk` remains unwiped.

The comment at lines 389–391 is factually wrong: `sk` is not “a `k256` type this crate does not own”; it is this crate’s own `scalar::Scalar`. This is the same copy-source defect class as E-178, now involving the final derived ElGamal secret.

**Falsified by:** showing that `scalar::Scalar` has a zeroizing destructor, aliases `wrapped`, or is explicitly zeroized before `finish()` returns. None is true in the frozen source.

## 4. MEDIUM — The rewritten comment stripper still false-passes; its safe-direction claim is false

**FILE:** [tools/check-zeroize-bounds.py:504–546]($REPO/tools/check-zeroize-bounds.py:504), [control at line 810]($REPO/tools/check-zeroize-bounds.py:810)

Two exact counterexamples:

- Legal nested comment:

  ```rust
  /* outer /* inner */
  let raw = Zeroizing::new(
  */
  ```

  **MEASURED:** the needle remains once after stripping because the scanner treats the inner `*/` as closing the outer comment.

- Valid raw string:

  ```rust
  const DECOY: &str = r#"let raw/*x*/= Zeroizing::new("#;
  ```

  **MEASURED:** the raw input contains zero copies of `let raw = Zeroizing::new(`, but stripping synthesizes exactly one by replacing `/*x*/` with a space. This directly disproves “never easier.”

An exact decoder-signature needle placed in a raw string also counts as present. A needle containing `//` or `/*` itself instead becomes harder or impossible to satisfy; `*/` inside a `//` line is skipped. Neither rescues the universal claim.

**Falsified by:** a nesting- and string-aware Rust lexer, or controls for nested comments and raw-string synthesis that the real detector catches.
