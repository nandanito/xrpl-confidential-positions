## S1 — HIGH (latent). The generators can emit the defect this branch exists to fix, and nothing would catch it.

`summarise()` in `tools/build-claims-index.ts` strips backticks but **not
pipes**:

```
.replace(/`/g, "")
```

So a claim headline containing `` `a|b|c` `` — a grep alternation, which this
register uses constantly — becomes `a|b|c` in the emitted row, where the pipes
are **structural**. The generated row then carries extra cells, and in the topic
files it would render as a broken row: **precisely the E-244 defect, produced by
the fix for E-244.**

⚠ **And neither generated file is in `check-table-integrity.ts`'s `TARGETS`**,
which is `["CLAIMS.md", "UPSTREAM-FEEDBACK.md"]`. Nothing shape-checks
`docs/CLAIMS-INDEX.md` or the 13 files under `docs/claims/by-topic/`.

**Measured:** 0 current headlines would emit a stray pipe, so this is latent, not
live. **Verified the probe works** by injecting a row with a stray pipe and
confirming the check catches it — an absence found by a detector never run
against a positive is not a measurement (E-165).

**Falsified if:** a headline containing a pipe is shown to survive `summarise()`
escaped or stripped.

## S2 — MEDIUM. `headline()` is fragile, and the override list is HIDING that rather than disclosing it.

`headline()` takes the first bold run, non-greedily:

```

```

`E-17`'s claim opens `**When set**, \`sfDomainID\` on the \`MPTokenIssuance\`
gates confidential transfers…`. The extracted headline is **`"When set"`** — nine
characters that say nothing. It matches no topic, and I resolved that by adding
`"E-17": ["protocol-and-crypto"]` to `OVERRIDES`.

⚠ **That is the wrong repair and I made it without noticing the mechanism.** The
override records *the patterns do not reach this row*, when the truth is *the
extractor threw the row's content away*. One row is affected today; the next row
that opens with a short bolded lead will be too, and the override list will grow
to hide each one individually.

**Falsified if:** `E-17`'s headline is shown to be a fair summary of its claim.
