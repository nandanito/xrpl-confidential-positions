**Row statuses:** `SUPPORTED` evidence attached · `PENDING` asserted, evidence not attached, **may not be published** · `RETRACTED` was claimed, found wrong — the row is kept, not deleted.

**Grades** are free text in the third cell. The conventions in use are `A, read at source`, `A, executed`, `A, recorded`, and qualifiers such as `not built or executed`, `F-12 not re-run`, `sizes not re-measured`.

**Two further project rules that bear on these rows:**

- *"A named gap is a correct output; a substituted source is a corrupted one."* If a primary source is unreachable, the row must record that and stop. It must not backfill from secondary coverage and must not quietly drop the question.
- *"Never claim more security than is delivered."*

**Failure modes this project has recorded in itself, repeatedly, in rows of exactly this kind.** They are given so you know what to hunt for; do not assume any of them is present here.

1. **A count restated in prose rather than derived.** Wrong thirteen separate times. Any number in a claim cell — "three of five", "seven more", "one short", "two ways" — is a claim with its own falsifier.
2. **A corpus-wide negative without the search that would settle it** (rule P-12 above). *"Nothing says X"*, *"no issue about Y"*, *"not among the reference papers"*, *"never says"*, *"has no threshold"*. The search must be **in the row**, and it must be a search that could have failed.
3. **A claim cell that outruns its evidence cell.** The evidence establishes a narrower thing than the headline asserts. The project's own phrase for this is *"a sentence one layer away from where the property breaks"*.
4. **A reading presented as a run, or a run's scope overstated.** Reading source at a branch is not evidence about what a live network runs.
5. **A `Not checked:` list that does not cover the row's actual gaps.** The disclosure is the warrant; if it names the wrong residual, it reads as a disclosure while hiding one.
6. **A correction that corrects the prose quoted rather than the defect named.**
7. **A shared evidence cell.** Some rows carry several sub-findings; evidence for one can read as evidence for its neighbour.
