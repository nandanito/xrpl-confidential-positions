# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
by reference. Its text at that address is the code of conduct for this
repository's issues, pull requests and discussions.

## Reporting

Report unacceptable behaviour privately to the repository owner, through
GitHub's private reporting on this repository: the **Security** tab, then
**Report a vulnerability**, with "conduct" in the title. The report is seen only
by the repository's maintainers.

The owner will review each report and act as the Covenant's enforcement
guidelines describe.
