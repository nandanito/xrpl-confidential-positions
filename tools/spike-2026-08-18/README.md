# Session 4 spike — the nonce patch

**Throwaway harness code. Not library code. Do not build on it.** Committed for
the same reason as `tools/spike-2026-08-17/`: under standing prohibition **P-8**,
a value whose generator is unavailable is not checkable. The vectors in
`t1-vectors.json` and the claims in `CLAIMS.md` E-60 to E-62 and F-18 come from
these files.

**Start with `WCONF-PATCH.md`.** It is the design record; this file is just the
index.

**Devnet only.** `devnet-send-our-nonces.ts` routes through the 2026-08-17
spike's `convert.ts`, which refuses any `network_id` but 2.

## What each file is

| File | Purpose |
|---|---|
| `WCONF-PATCH.md` | **Read first.** What changed in mpt-crypto, why, what was tested, and what is out of scope |
| `wconf-nonces.patch` | The fork itself: a six-file diff against `XRPLF/mpt-crypto` at `85dbac73d033241b73f0565ae7cce86d07005c70`. Applies cleanly to a pristine checkout and reproduces the working tree byte-for-byte |
| `vendor-verify.sh` | The CI assertion REVIEW-005c §3 asked for — only the six allowed files differ, the clawback sentinel survives, no call site reaches the deleted function, and the hedge flag still defaults to off |
| `build.sh` | Builds the patched library, the **pristine** control library, both `mptool` binaries, `wconf-kat` and `t-nbound`. No Conan |
| `nonce-crosscheck.ts` | 14 checks, no network. The decisive one: the pristine upstream verifier accepts a proof from our patched prover, at n=3 and n=4 |
| `t1-vectors.ts` | The 13 T-1 known-answer vectors, each generated by the C and reproduced by an independent TypeScript implementation written from the spec prose, plus 8 separation properties |
| `t1-vectors.json` | The committed vectors. `t1-vectors.ts` fails if they drift |
| `wconf-kat.c` | Exposes `wconf_generate_nonces` directly so the vectors have a runnable generator |
| `t9-entropy.c`, `build-t9.sh` | T-9: counts entropy draws per proof by overriding `RAND_bytes` for all statically linked callers. Runs both arms |
| `t-nbound.c` | Regression test for the HIGH finding of the 2026-08-18 review — huge participant counts must be rejected before any allocation. **Judge by exit code**, not by grepping output; with the guard removed it aborts partway after printing misleading PASS lines |
| `devnet-send-our-nonces.ts` | **The objective.** Builds a `ConfidentialMPTSend` with our nonces and submits it. Gates on local verification by the pristine upstream verifier before spending a transaction |

## The order things run in

```bash
./vendor-verify.sh          # or ./vendor-verify.sh /tmp/wconf/mpt-crypto
./build.sh
bun nonce-crosscheck.ts     # must pass before anything is submitted
bun t1-vectors.ts
./build-t9.sh
/tmp/wconf/t-nbound         # exit 0 required
bun devnet-send-our-nonces.ts
```

## Adversarial review

Reviewed 2026-08-18 by two independent legs, Codex and Gemini. One HIGH defect
(a heap out-of-bounds write from unchecked participant-count arithmetic, which
this patch's own refactor introduced), three LOW, and two evidence gaps — all
fixed or closed. Findings and dispositions are in `WCONF-PATCH.md` §7; the
Gemini leg is verbatim at
`docs/reviews/REVIEW-009-gemini-nonce-patch-2026-08-18.md`. Both legs
independently found the same uncleansed-buffer defect, and neither found a defect
in the wide reduction or the Fiat–Shamir transcript.
